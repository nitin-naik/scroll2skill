# Edit plan: "You don't need a fancy camera" (CapCut → Reels + Shorts)

**Changes in short:** move your 50K line to the very start, cut "okay so", "and um yeah", "see you there" and every gap between sentences, and end on the CTA. **That takes the video from 52 s to about 40 s.** It's a talking-to-camera list ("tip one… tip four"), so use the **one-take with overlays** pace. There are no scene changes. Something new comes on screen every 1–2 s: captions, a "TIP 2/4" label, proof overlays and small zooms. You get exactly **2 pattern interrupts**.

## 4. CapCut steps

Menu names differ between versions and between mobile and desktop. Check them in your version.

- **Reorder:** split at 0:04 and 0:09 (Edit → Split). Drag the "I started with this phone…" clip to the start.
- **Cut fillers and gaps:** put the playhead on each gap, then Split and Delete. Faster *(inferred)*: CapCut desktop has **Remove silences / Auto cut** in the clip's right-click menu or the Edit panel. Check every cut afterwards so it doesn't clip the start of words.
- **Captions:** Text → **Auto captions**, language English, then Generate. Then fix every misheard word. "fifty thousand" should read "50,000", "YouTube" should be spelled correctly, and "CapCut" often comes out wrong. Auto-captions mishear names and jargon.
- **Caption style** *(inferred menu names)*:
  1. Tap one caption and open Edit → Font. Pick a bold sans-serif (e.g. Montserrat Black or a similar heavy sans).
  2. Set the colour to white.
  3. Turn on Stroke or Shadow in black, and use all caps.
  4. Tick **"Apply to all captions"**.
  5. Put the captions in the centre or slightly below. Keep them out of the bottom 20% and away from the right edge, where the like and comment buttons sit.
  6. Shorten long captions to 1–4 words by splitting them in the caption editor.
- **Emphasis word:** open the caption and select just that word, then set its colour to yellow and its size to about 120%. If your version can't style one word, split it into its own caption.
- **Zooms** *(inferred)*:
  - **Punch-in (Interrupt 1):** split at 7.4 s. Select the new clip, go to Edit → Adjust/Basic → Scale and set it to 135%. Don't use a keyframe ramp, so it snaps.
  - **108% jump-cut hides:** set Scale to 108% on every other clip.
- **Overlays:** Overlay → Add overlay for screen recordings and stock. Drag each into the upper half. Use Mask → Rectangle with rounded corners for the picture-in-picture look.
- **Section label and progress bar:**
  - **Label:** Text → Add text ("TIP 1/4"). Make it small and place it top-centre.
  - **Progress bar:** use 4 rectangles. In Text, use "■" characters, or a shape sticker from Stickers. Change the fill colour of one segment for each tip.
- **Full-screen card (Interrupt 2):** add a black background, using Overlay with a black image or Canvas → Colour on a split clip. Add text on top and set the length to 0.8 s.
- **Sound effects:** Audio → Sound effects, search "whoosh" and "pop".
- **Voice clean-up** *(inferred)*: select your clip, go to Audio → **Enhance voice** (or Reduce noise), then turn on **Normalize loudness**.
- **Ending:** remove CapCut's auto-added ending clip. In mobile settings *(inferred)*, turn off "Add default ending". Don't use a CapCut template watermark.

## 5. Export and posting

- **Export:**
  - 1080 × 1920 (9:16) at 30 fps. Use 60 fps if you filmed at 60. Don't upscale to 4K unless you shot in 4K *(inferred)*.
  - Set bitrate to "Recommended/High" *(inferred)*.
- **Music:**
  - Export **voice and sound effects only**. Then add music inside each app from its licensed library, at low volume (about 10–15% in Instagram's mixer, or "low" in YouTube's music add) *(inferred)*. This avoids copyright muting.
  - Pick an instrumental with a steady beat.
- **Instagram Reels:**
  - **Caption** (the post text under the video). Example: "You don't need a fancy camera. 4 things that got me to 50K on a phone 👇 Part 2: my exact editing setup." Add a few topic hashtags.
  - **Cover:** choose the 0:00 frame, or a frame with the "PHONE → 50K SUBS" text.
  - Turn on Settings → Account → Data usage and media quality → **Upload at highest quality** *(inferred)*.
- **YouTube Shorts:**
  - **Title**, kept under about 60 characters so it isn't truncated. Example: "Phone to 50K subs: 4 rules that mattered more than the camera" *(inferred)*.
  - Add music through the Shorts editor's "Add sound".
  - You can pick a thumbnail frame in the mobile app *(inferred)*. Use the 0:00 frame.
- **Both platforms:** post the same edit to both. Don't upload a version with another app's watermark.
